# 咪咪色彩英语

独立儿童学习站预览版。小猫咪咪陪孩子认颜色、学英语；也收录「玩转色彩」36 个颜色实验。

## 网址

**https://pomosherry-hue.github.io/mimi-web/**

`qr.png` 就是这个网址的二维码，可以直接印出来或发到微信。

## 预览说明

- **咪咪色彩英语**：13 集动画、封面和单词卡已放在本站，可以直接播放。
- **玩转色彩**：课程视频使用 kids-color 站点上的公开地址，一般也可以直接看。
- 不用注册，不用下载 App。扫码或用浏览器打开即可。

## 文件

- `index.html` 首页目录，大色块，适合手机点选
- `play.html` 播放页（单词卡和歌词）
- `episodes/` 咪咪色彩英语的视频、封面和单词卡
- `qr.png` 网址二维码
